# 界面样式来源

v0.2.3 的布局方向参考 [EcoPaste](https://github.com/EcoPasteHub/EcoPaste) 的浅色小窗，由用户在原项目截图与交互预览中选定。

参考要素为紧凑搜索栏、图标分类、约 12px 的列表边距、8px 卡片圆角、浅边框与蓝色选中态。超强大脑仍为独立的 C# / WPF 轻量软件，使用自己的品牌、矢量图标、备忘录和本地加密密码库实现，未引入 React、Tauri 或浏览器运行时。

参考位置：EcoPaste 的 `src/pages/Clipboard/components/Header.tsx`、`Group.tsx`、`cards/ClipboardCard.tsx`、`List.tsx`。原项目以 [Apache License 2.0](https://github.com/EcoPasteHub/EcoPaste/blob/master/LICENSE) 发布。本项目没有复制上述实现源码或原品牌素材，此处注明设计参考来源。

旧版置顶标志继续使用同一数据字段，在新版界面中表现为收藏。图片透明度仅作用于背景图，文字与控件保留独立底色。新建配置使用蓝白主题；只升级旧版默认配色组合，不重置用户的自定义背景、图片、快捷键或窗口位置。
