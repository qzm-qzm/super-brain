# 更新与发布

GitHub 保存源码和下载文件，个人资料始终留在本机。v0.2 起不再生成安装器，也不捆绑 Electron。

## 日常更新

1. 设置中导出备份。
2. 从设置「查看新版本」进入 GitHub Releases。
3. 退出工具，替换运行文件，保留原 data 文件夹。
4. 双击重新运行。

尚不提供自动下载安装。运行文件可以更名，但同目录保留一份即可。

## 修改和验证

Windows 10/11 x64 需 .NET Framework 4.8+；编译无需额外 SDK 或 npm 依赖。PowerShell 7：

```powershell
./scripts/build-lite.ps1
./scripts/build-lite.ps1 -Tests
./dist-lite/NativeTests.exe ./test-results/native
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/smoke-lite.ps1 -Executable ./dist-lite/超强大脑.exe -TestRoot ./test-results/standalone
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/smoke-background.ps1 -Executable ./dist-lite/超强大脑.exe -TestRoot ./test-results/background
```

只在测试通过后发版。`native/Models.cs` 负责资料和备份，`native/Vault.cs` 负责加密与锁定，`native/BrainWindow.cs` 和 `native/Dialogs.cs` 负责界面，`native/Platform.cs` 负责快捷键和单实例。

`native/BackgroundHost.cs` 负责托盘、后台快捷键和窗口进程生命周期；`native/StartupRegistration.cs` 管理当前用户的登录启动项。后台测试检查静默启动、快捷键交接、重复运行、保存后释放窗口、启动中退出，并记录工作集和空闲 CPU 用时。

## 发布新版

例如从 0.2.0 更新到 0.2.1：

```powershell
./scripts/set-version.ps1 -Version 0.2.1
# 更新 CHANGELOG.md，再完成构建和测试
git add native CHANGELOG.md
git commit -m "feat: describe your change"
git tag -a v0.2.1 -m "Super Brain Lite v0.2.1"
git push origin main --follow-tags
```

main 推送自动构建并提供 Actions artifact。`v*` 标签校验版本、编译、运行存储和真实窗口测试，再发布：

- 单文件 `SuperBrain.exe`。
- 含中文运行文件和使用说明的 `SuperBrain-Lite-版本号-win-x64.zip`。
- SHA256SUMS.txt。

发布任务先建草稿、上传完整产物再公开；不覆盖已有公开版本。若构建失败，修复后先重新验证 main；已经公开的版本请递增版本号再发布。

## 旧版

旧 Electron 实现在 v0.1.0 标签下。v0.2 不修改旧版 AppData 文件，也不直接导入旧加密备份。数据迁移需单独处理并保留原备份。
