# 数据与安全

超强大脑把普通备忘录和密码库分开保存，保护方式不同。

| 内容 | 保存位置与保护 |
| --- | --- |
| 普通备忘录、配色、背景图片、设置 | `%APPDATA%/SuperBrain/notes.json`，明文 |
| 账号条目的标题、用户名、密码、网站和备注 | `%APPDATA%/SuperBrain/vault.enc.json`，整个条目列表加密 |
| 导出备份 | 用户选择的 JSON 文件；普通备忘录明文，密码库仍加密 |
| 上一版数据和恢复前备份 | 数据目录中的 `.bak`、`before-restore-*.json`；保护方式与原资料一致 |

## 密码库的保护

应用使用 Node.js 自带的密码学库，以 scrypt 从主密码派生 256 位密钥，再使用 AES-256-GCM 加密密码库。scrypt 参数为 `N=131072, r=8, p=1`，随机盐为 32 字节。每次加密生成新的 12 字节随机 nonce，保存 16 字节认证标签，用于检测密文损坏或被修改。

主密码不写入数据文件。锁定会清除应用持有的密钥缓冲区并移除界面中的账号列表，但 JavaScript 运行时无法保证所有字符串副本立即从进程内存中物理擦除。

**遗失主密码就无法解密密码库。** 修改主密码不会更新你此前导出的备份；旧备份、上一版 `.bak` 和恢复前备份可能仍需旧主密码。如果是因旧主密码泄露而更换主密码，也需要单独处理仍受旧密码保护的备份。

## 自动锁定与复制

收起窗口、锁屏、休眠、手动锁定和闲置超时都会锁定密码库。复制账号或密码 30 秒后，若剪贴板仍是这次复制的内容，应用会清空它；锁定时也会尝试清除。

这一机制不能删除 Windows 剪贴板历史、跨设备剪贴板或其他剪贴板管理器已经保存的副本。密码库也不能阻止恶意软件读取已解锁进程、记录键盘或截屏。共享电脑上应分别使用自己的 Windows 账号。

## 网络与 GitHub

应用没有注册、云同步和遥测功能，不会上传备忘录或密码库。用户主动「检查更新」时，请求 `api.github.com/repos/qzm-qzm/super-brain/releases/latest`，获取公开版本信息；请求包含应用版本号的 User-Agent，不包含个人记录或主密码。打开仓库和下载页面会交给默认浏览器。

GitHub 用于保存代码和分发安装包。不要把数据目录、导出备份、真实账号或密码放入仓库或问题报告。分享截图前也应检查内容。

## 安装包和项目现状

当前安装包没有 Windows 代码签名证书，可能被系统标记为未知发布者。每次正式发布附带 SHA-256 校验文件，便于确认下载完整性；校验值与安装包一起托管，不能替代发布者身份认证或第三方安全审计。

当前版本尚未经过独立安全审计。测试覆盖存储、加密和部分真实桌面交互，不代表已通过密码管理器的完整安全认证。
