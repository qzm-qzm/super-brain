# 数据与安全

## 保存位置

配置在 `data/config.json`，普通备忘录在 `data/notes.json`，密码库在 `data/vault.enc.json`。data 位于运行文件旁边，不使用 AppData；首次创建密码库前不会生成密码库文件。

普通备忘录、背景图片和配置明文保存。账号条目的标题、账号、密码、网站和备注整体加密。导出备份和自动留下的 `.bak`、恢复前备份具有相同的保护边界。

## 轻量版密码库 v2

使用 Windows CNG 的 PBKDF2-HMAC-SHA256，以 600,000 次迭代、32 字节随机盐从主密码派生 64 字节密钥；分为独立的 32 字节加密密钥和 32 字节 MAC 密钥。使用 AES-256-CBC / PKCS7 加密，每次生成新的 16 字节 IV，再以 HMAC-SHA256 认证格式域、盐、IV 和密文（先加密再认证）。读取时先检查固定版本及参数，再以固定长度循环比较 MAC，认证通过后才解密。

实现使用 .NET/Windows 自带密码学 API，不自行实现加密算法。测试将原生 PBKDF2 结果与 .NET 参考实现比较，并验证密文、IV、盐与 MAC 篡改拒绝。密码派生在后台进行；锁定期间完成的旧解锁操作不能重新打开密码库。

主密码不写入磁盘。锁定清除持有的密钥字节数组和界面账号内容；托管运行时不能保证所有字符串副本立即物理清零。恶意软件、键盘记录器、管理员和已解锁进程的内存读取不在防护范围内。

**主密码无法找回。** 修改主密码不改变已经导出的旧备份；旧 `.bak` 和恢复前备份可能仍需旧主密码。

## 保存与恢复

写入临时文件、刷新文件，再原子替换，保留上一版 `.bak`。读取损坏的数据时报告错误，不用空文件覆盖原资料。普通记录延迟 250 毫秒合并保存，窗口关闭前刷新；密码编辑立即加密并写入。写入失败时保留待重试的加密记录并显示错误。

恢复备份先验证格式、留下恢复前备份，然后替换资料。恢复失败时尝试回滚原数据。单数据文件上限 16 MiB，组合备份上限 36 MiB。

## 剪贴板与网络

复制后 30 秒，仅当当前剪贴板仍等于此次复制内容时清空；锁定时也清理。本机制不能清除 Windows 剪贴板历史或其他管理器的副本。

工具无账号、云同步、遥测或后台网络请求。打开新版本页或源码页会调用浏览器访问 GitHub。源码仓库和发布包不包含个人资料。不要上传 data 文件夹或真实密码截图。

## 发布状态

运行文件没有代码签名，Windows 可能提示未知发布者。SHA-256 校验用于确认文件完整性，不能代替发布者身份认证或独立安全审计。当前尚未经过独立安全审计。

v0.1.0 使用不同的 scrypt/AES-GCM 格式，轻量版不直接读取旧版密码文件，以免错误覆盖原资料。
