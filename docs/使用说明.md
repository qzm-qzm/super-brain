# 使用说明

## 启动与收起

把压缩包解压到自己的文件夹，双击 `超强大脑.exe`。无需安装。运行后按 F8 呼出/收起；设置中点击快捷键框，再直接按想绑定的功能键或组合键，最后点击「保存设置」。只按字母或数字不会绑定，以免影响其他软件输入。若按键已被占用，会提示更换，原快捷键继续可用。工具完全退出后，快捷键不会继续生效。

右上角关闭按钮将窗口收起到托盘。托盘右键可以打开、锁定或退出。再次双击运行文件会打开已有窗口。

在「设置」勾选「登录 Windows 后后台启动」并保存。软件会创建当前用户的 Windows 登录任务，登录桌面后静默待命，直接按你绑定的快捷键即可打开。任务不要求电脑空闲或外接电源。取消勾选会移除该任务，仅影响当前 Windows 用户，下次登录不再自启；当前已运行的后台会保留到你主动退出。

从 v0.2.4 / v0.2.5 升级后，再保存一次已勾选的后台启动设置，即可迁移旧 Run 启动项。若下次登录仍不能呼出，可在「任务计划程序」查找 `SuperBrainLite-` 开头、属于当前用户的任务，检查最近运行时间和结果。

收起窗口会保存资料、锁定密码库并释放窗口进程，后台仅保留快捷键和托盘。下次呼出重新加载列表，密码库需要解锁。彻底退出后本次登录期间不再响应快捷键；下次登录仍会按自启动设置运行。移动或重命名运行文件后，需要从新位置重新开启自启动。

按住顶部“超强大脑”标题即可拖动小窗，边缘可调整大小。工具会记住位置与尺寸；换显示器后若原位置不可见，会把窗口移回屏幕。

## 备忘录与密码

点击「新建」，填写标题和内容，自动保存。点击卡片右上角星标收藏，分类栏星标可切换“只看收藏”；旧版置顶记录会直接显示为收藏。可从顶部搜索，Ctrl+F 聚焦搜索框。删除后的 10 秒内，在列表按 Ctrl+Z 撤销；收起释放窗口后不能撤销。编辑页 Esc 返回列表，列表 Esc 收起，Ctrl+S 立即保存。

「密码库」首次打开需设置非空主密码，长度由你决定。账号、密码、网站、标题和私密备注全部加密。主密码无法找回，请另行妥善记住。需要私密保存的文字可以写到账号条目的备注里。

已有密码不会因软件更新自动改变。先用原主密码解锁，再从「设置 → 修改主密码」换成你想用的新密码。修改后新密码用于当前密码库，旧备份仍需对应的旧主密码。

收起、锁屏、休眠或闲置后自动锁定。设置中可选择 1/5/10/15/30 分钟，默认 5 分钟。复制后 30 秒清除本次复制的剪贴板内容；Windows 剪贴板历史不会因此删除。

## 外观

右上角齿轮打开外观，可选择六种主题、自定义背景与主题色、选择 PNG/JPG 背景图片（最大 2 MB）。透明度 0% 表示图片不透明，100% 表示完全透明；数字越大越淡。卡片和按钮使用独立的实色底，调整图片不会使文字一起变淡。右下角齿轮打开快捷键、备份等设置。

颜色与透明度自动保存，图片内容一并保存在本地配置内，移动文件夹后不依赖原图片路径。

## 资料与备份

全部资料在运行文件旁边的 `data` 文件夹。请把文件放在可写文件夹，例如 D:\super-brain；不要直接在压缩包中运行，也不建议放在 Program Files。

设置里可以打开数据文件夹、导出备份、恢复备份。普通备忘录和配置在备份中仍是明文，密码库仍然加密。恢复会替换当前资料，并先在 data 中留一份恢复前备份；恢复不自动更换全局快捷键。

换电脑时退出工具并复制整个文件夹即可，加密密码库仍需原主密码。更新时只替换运行文件，不要删除或覆盖 data。

## 旧版资料

v0.1.0 的资料位于 `%APPDATA%/SuperBrain`，轻量版不会删除或自动迁移它。v0.1.0 的加密备份与轻量版格式不同，请保留旧版和旧备份，使用旧版解锁后迁入；不要直接覆盖新数据文件。

## 测试资料隔离

开发时可通过 `--data-dir "独立测试文件夹"` 指定测试目录。普通双击启动无需任何参数，默认始终使用运行文件旁的 data。

`--background` 仅后台待命；`--enable-startup` / `--disable-startup` 为当前运行文件开启或关闭登录启动，执行后立即退出。测试程序使用独立的任务名称和注册表测试子项，完成后删除，不修改真实启动设置。
