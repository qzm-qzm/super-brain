# 使用说明

## 打开与收起

软件运行后，默认按 `Alt + Q` 呼出或收起。你也可以点击系统托盘中的图标。窗口关闭按钮只会收起软件，彻底退出请使用设置中的「退出软件」或托盘菜单的「退出」。

设置里可以修改快捷键，例如 `Alt+Q`、`Ctrl+Shift+B` 或单键 `F8`。如果快捷键已被其他程序占用，软件会提示更换。单个字母或数字不能作为全局单键快捷键，避免干扰日常输入。

`Esc` 在编辑页面返回列表，在列表页面收起窗口；对话框打开时先关闭对话框。`Ctrl + S` 可以立即保存当前编辑内容，正常输入也会自动保存。

安装版可以在设置中勾选「开机启动」，登录 Windows 后在托盘中待命。免安装版暂不支持该选项。窗口支持拖动、调整大小和设置始终置顶。

## 普通备忘录

在「备忘录」页签中点击新建，填写标题和正文。点击列表中的一条记录即可继续修改。搜索会匹配当前页签内的内容，置顶记录排在前面。删除后可以用短暂出现的「撤销」恢复；这不是长期回收站。

普通备忘录以明文文件保存。密码、验证码恢复码等敏感内容应放在加密的「账号密码」条目中。

## 账号密码

第一次使用「账号密码」时，设置至少 12 个字符的主密码。之后用这个主密码解锁本地密码库，再新建或修改账号条目。

每条可以填写名称、用户名、密码、网站和备注。密码默认隐藏，可以临时显示、复制，也可以生成 24 位随机密码。复制的账号或密码在 30 秒后尝试清除：只有剪贴板仍是这次复制的内容时才清空，避免删除你后来复制的其他内容。

默认闲置 5 分钟锁定，可以改为 1、5、10、15 或 30 分钟。收起窗口、锁屏和休眠也会锁定密码库。解锁后可以在设置中修改主密码；**旧备份仍需旧主密码解锁**。

主密码遗失后无法找回。没有服务器保存解密密钥，也不能通过登录 GitHub 解锁资料。

## 配色与背景图片

点击右上角调色盘即可打开外观设置。可以选择六种预设、自定义背景色和主题色；文字颜色会根据背景调整。

背景图片支持 PNG、JPG 和 WebP，最大 2 MB。选择图片后，透明度滑块会启用：0% 完全显示图片，100% 完全透明，数值越大图片越淡。它不改变文字透明度。设置自动保存在本机，可移除图片或恢复默认外观。

## 备份与恢复

在「设置 → 资料与备份」中导出 JSON 备份。它包含备忘录、设置、背景图片，以及仍然加密的密码库。普通备忘录没有因为导出而被加密。

恢复备份会替换当前资料，需要在对话框中确认。恢复前软件会在数据目录留下 `before-restore-时间戳.json`，用于找回原有资料。恢复不会自动替你更换全局快捷键或改变 Windows 开机启动设置。

密码库恢复后保持锁定，需要该备份原来的主密码。建议把备份复制到你控制的另一块磁盘；备份和软件放在同一块磁盘，不能防止整块磁盘故障。不要将个人备份提交到公开仓库。

## 数据目录与换电脑

在设置中点「打开数据目录」，或者在资源管理器地址栏输入：

```text
%APPDATA%\SuperBrain
```

主要文件是 `notes.json` 和 `vault.enc.json`；`.bak` 文件是写入时保留的上一版。安装版和免安装版使用同一个用户数据目录。覆盖安装新版本不会更改这个位置，卸载配置也保留用户资料。

换电脑时，先导出备份，在新电脑安装软件后恢复即可。复制免安装 EXE 本身不会带走资料。密码库不绑定原来的 Windows 账号，仍需正确的主密码。

## 开发时隔离测试资料

自动检查可以直接运行 `npm run test:desktop`。脚本自行创建 `test-results/desktop-smoke-*` 独立目录，通过 Playwright 启动 Electron 并填入虚构记录；无需手动设置下面的环境变量，也不需要额外安装 Playwright 浏览器。结果与截图保存在该次运行目录中。

在仓库目录执行以下 PowerShell 命令，让本次开发进程使用单独目录：

```powershell
$env:SUPER_BRAIN_TEST = '1'
$env:SUPER_BRAIN_TEST_DATA_DIR = Join-Path $PWD 'test-results/manual-profile'
npm start
```

测试模式会禁止修改开机启动设置，首次窗口隐藏，可以点击托盘图标呼出。环境变量只影响当前终端会话；结束后关闭终端即可。正式日常使用请启动安装好的应用。
