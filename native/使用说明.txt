超强大脑 · 轻量版

1. 解压到可写文件夹，双击「超强大脑.exe」，无需安装。
2. 默认 F8 呼出 / 收起；在设置中点击快捷键框，直接按想绑定的键，再保存。工具退出后快捷键不生效。
3. 关闭按钮收起到托盘，设置或托盘右键可以彻底退出。
   按住顶部“超强大脑”标题可拖动窗口；位置和大小会保存。
4. 配置、备忘录、背景图片和密码库都在同目录 data 文件夹。
5. 普通备忘录为明文，账号密码加密保存。请牢记主密码，遗失无法找回。
6. 外观中可改配色、背景图片和图片透明度。
7. 设置里导出 / 恢复备份。移动时带上 data，更新时只替换运行文件。

需要 Windows 10/11 x64 与 .NET Framework 4.8+（现代 Windows 通常已包含）。
旧版 v0.1 加密备份不能直接导入，请保留原资料和旧版。

源码与更新：https://github.com/qzm-qzm/super-brain
